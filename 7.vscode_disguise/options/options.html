Cài đặt Code Focus

Cấp 1: chỉ đổi tên tab và icon.
Cấp 2: cấp 1 + khung giao diện soạn code bao quanh trang (trang vẫn dùng bình thường). Hợp với trang tương tác như Study4.
Cấp 3: cấp 2 + chữ của trang hiện thành dạng code có số dòng (chỉ đọc, ẩn trang thật). Hợp với trang chữ như Cambridge Dictionary.

Trang đã nhớ: 0. Trang nào bạn bật bằng popup hoặc phím tắt sẽ tự bật lại ở các lần mở sau, bật "Tắt" để quên trang đó.

Phím tắt bật/tắt: Alt+Shift+V (đổi ở chrome://extensions/shortcuts). Bấm biểu tượng extension để chọn cấp độ bằng tay.
